# 🎵 RagaLens

### Repository : https://github.com/barnikbasu/RagaLens/
### Live Demo : https://ragalens.vercel.app/

### AI-Powered Exploration of Indian Classical Music

RagaLens is an AI-assisted web platform designed to help users explore, understand, and interact with the rich world of Indian Classical Music. The platform combines modern web technologies with intelligent information retrieval to create an engaging and educational musical experience.

## 🚀 Features

* 🎼 Explore Indian Classical Ragas
* 🤖 AI-Assisted Information Retrieval
* 🔍 Intelligent Search and Discovery
* 📚 Educational Music Insights
* 🎵 Structured Raga Information
* ⚡ Fast and Responsive User Interface
* 🌐 Modern Web-Based Experience
* 📱 Mobile-Friendly Design

## 🛠 Tech Stack

### Frontend

* Next.js

* Tailwind CSS

### Backend & Deployment

* Firebase

### AI & Intelligence

* Large Language Models (LLMs)

## 🎯 Motivation

Indian Classical Music contains centuries of musical knowledge, traditions, and theoretical depth. However, discovering and understanding ragas can often be challenging for beginners and enthusiasts.

RagaLens aims to bridge this gap by creating an accessible platform that combines technology and music education, enabling users to learn about ragas in an intuitive and interactive way.

## 💡 Use Cases

* Students learning Indian Classical Music
* Musicians exploring ragas
* Music researchers
* Cultural enthusiasts
* AI-assisted educational applications
* Digital preservation of musical knowledge

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/barnikbasu/RagaLens.git
```

Navigate to the project directory:

```bash
cd RagaLens
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
